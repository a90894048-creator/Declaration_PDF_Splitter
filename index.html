📄 신고번호 PDF 분할기

스캔한 PDF의 좌측 상단 신고번호를 읽어 신고번호별 PDF로 나눕니다. 파일은 이 PC 브라우저 안에서만 처리됩니다.

1. PDF 파일 선택

여기에 PDF를 끌어놓거나 클릭해서 선택하세요 (여러 개 가능)

2. 인식 설정

영역 미리보기 (첫 파일 1페이지) — 빨간 상자 안에 신고번호가 들어오게 맞추세요
파일을 선택하면 표시됩니다.

3. 분석

처리하는 동안에는 이 탭을 화면에 띄워 두세요. 다른 탭으로 가거나 창을 내리면 브라우저가 작업을 멈춥니다.

4. 결과 확인 및 저장

신고번호가 읽힌 페이지(초록)에서 새 파일이 시작되고, 번호가 없는 페이지는 앞 파일에 이어 붙습니다. 같은 번호가 연속되면 한 파일로 합칩니다. 잘못 읽힌 번호는 직접 고치고, 번호를 지우면 앞 파일에 이어집니다.

💡 탐색기에서 PDF 미리보기가 안 되면: 받은 ZIP을 오른쪽 클릭 → 속성 → '차단 해제' 체크 → 확인 후 압축을 푸세요. (Windows가 인터넷에서 받은 파일의 미리보기를 막기 때문입니다.)
